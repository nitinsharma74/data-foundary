Repository Overview

Data Foundary

A small collection of data engineering and ETL projects built around Databricks workflows. This repo currently focuses on an hourly weather pipeline and a Reddit sentiment analytics pipeline.

Hourly Weather Report

Ingests hourly NOAA weather observations for configured stations.

Normalizes the API response and writes the results to Delta tables in Databricks.

Runs on a schedule and powers a dashboard for quick hourly reporting.

Reddit Sentiment Analysis

Processes Reddit post and comment data prepared for ETL analysis.

Cleans records, flattens nested comments, and builds analytics-ready Delta tables.

Supports recurring dashboard reporting and sentiment trend analysis in Databricks.
